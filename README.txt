UNO PERFUMES — DIGITAL FRAGRANCE PASSPORT
===========================================

Files:
- index.html: responsive one-page passport website
- assets/fruit-of-the-forest-hero.png: forest hero artwork
- assets/fruit-of-the-forest-bottle.jpg: bottle photo provided by UNO

Preview locally:
1. Extract the ZIP.
2. Open index.html in a browser.

Unique bottle records:
Use the same published page with a query parameter:
?bottle=FOF-001-001
?bottle=FOF-001-002
?bottle=FOF-001-003

Example after hosting:
https://YOUR-SITE-ADDRESS/?bottle=FOF-001-001

IMPORTANT:
- This is a ready-made static website prototype, not yet live on the internet.
- QR codes should be generated only after the final public website URL is known.
- Replace draft story and every "to be confirmed" field with approved details before public launch.
- The bottle query parameter personalizes the displayed serial number; it is not anti-counterfeit verification.
- Static custom HTML cannot be imported directly into Google Sites as a complete website. For this exact design, publish the files using a static host such as GitHub Pages. If you must use Google Sites, recreate the layout with its editor instead.
